# Machine Learning Assignment 2: Diagnostic Classification

## Problem statement

The objective is to compare supervised classification algorithms for predicting whether a breast tumour is malignant or benign. The project implements the required models, calculates six evaluation metrics, and exposes the results through an interactive Streamlit application.

## Dataset description

The project uses the **Breast Cancer Wisconsin Diagnostic** dataset, originally published by the University of Wisconsin and distributed through the UCI Machine Learning Repository. The scikit-learn copy contains 569 instances, 30 real-valued diagnostic features, and two classes: malignant and benign. The data is split with stratification using `random_state=42`; 20% is retained as labelled test data.

## Models used and evaluation metrics

The assignment lists five named models despite referring to six models in one sentence. This implementation follows the explicit model list and comparison-table rows:

1. Logistic Regression with standardisation
2. Decision Tree Classifier
3. k-Nearest Neighbour with standardisation
4. Gaussian Naive Bayes
5. Random Forest (Ensemble)

Metrics are generated by running `python train_models.py` and are stored in `metrics.json`.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | A strong linear baseline; scaling is important because the diagnostic measurements have different numeric ranges. |
| Decision Tree | Easy to interpret and captures non-linear rules, but its constrained depth can limit recall compared with the ensemble. |
| kNN | Benefits from standardisation and local similarity; prediction quality depends on the selected neighbourhood size. |
| Naive Bayes | Fast and competitive, although its independent-feature assumption is imperfect because several medical measurements are correlated. |
| Random Forest (Ensemble) | Matches the best accuracy and has the highest F1 and MCC on this split; it also achieves perfect recall for the benign class. |
| **Overall winner** | Random Forest is the overall winner for this split because it has the highest F1 (0.973) and MCC (0.926), while tying the best accuracy (0.965). |

## Streamlit application

The app provides the required CSV upload, model dropdown, metric display, confusion matrix, and classification report. The default `test_data.csv` is used when no file is uploaded. The uploaded file must contain the 30 feature columns and a labelled `target` column.

Run locally:

```bash
python train_models.py
streamlit run app.py
```

Deploy `app.py` from this folder using Streamlit Community Cloud after pushing the folder to GitHub.
